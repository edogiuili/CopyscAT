# Example processed fragment matrix

Binned ATAC fragment counts for 1371 adult glioblastoma cells, in the
format produced by `process_fragment_file.py`. Used by the examples and
tests.

## Usage

``` r
scDataSamp
```

## Format

A data frame with 1371 rows (cells) and 3103 columns (1 Mb genomic
bins). Row names are cell barcodes; column names are `chrom_position`.

## Source

Adult glioblastoma single-cell ATAC sequencing.

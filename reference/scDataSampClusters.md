# Example cluster assignments

Cluster labels for the cells in
[scDataSamp](https://edogiuili.github.io/CopyscAT/reference/scDataSamp.md),
as consumed by
[`smoothClusters()`](https://edogiuili.github.io/CopyscAT/reference/smoothClusters.md).

## Usage

``` r
scDataSampClusters
```

## Format

A data frame with one row per barcode: the barcode in the first column
and its cluster label in the second.

## Source

Adult glioblastoma single-cell ATAC sequencing.
